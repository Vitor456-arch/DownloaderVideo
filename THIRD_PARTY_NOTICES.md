# Dependências e redistribuição

DownloaderVideo tem licença MIT. Essa licença não substitui as licenças das dependências.

- **yt-dlp** — Unlicense; https://github.com/yt-dlp/yt-dlp. O build coleta módulos Python da instalação oficial, não um executável de outra distribuição.
- **yt-dlp-ejs** — ver licença incluída em `packaging/licenses/yt-dlp-ejs`; scripts de resolução utilizados pelo próprio yt-dlp. Algumas plataformas também exigem um runtime JavaScript suportado pelo yt-dlp, que não é instalado por este projeto.
- **PySide6 / Shiboken / Qt** — LGPLv3/GPLv3 ou licença comercial, conforme o componente. Usamos QtCore, QtGui e QtWidgets, distribuídos como bibliotecas dinâmicas substituíveis em um pacote `onedir`. Os textos LGPLv3/GPLv3 estão em `packaging/licenses`. Fontes e licenças oficiais: https://code.qt.io/pyside/pyside-setup.git/ e https://code.qt.io/qt/qtbase.git/ ; obtenha as versões correspondentes às versões instaladas no arquivo `requirements-tested.txt`. Não restrinja os direitos de modificação, substituição ou engenharia reversa necessários para depuração de alterações das bibliotecas LGPL. É possível reconstruir este aplicativo com versões modificadas usando o código e os scripts fornecidos. Recursos de Qt não importados pelo aplicativo são excluídos do build.
- **Mutagen** — GPLv2 ou posterior; https://github.com/quodlibet/mutagen. Como o pacote redistribui esta dependência opcional do yt-dlp, a distribuição combinada deve respeitar a GPL aplicável. Os arquivos próprios do aplicativo continuam disponíveis em MIT; isso não torna a distribuição combinada isenta de obrigações GPL. Fontes correspondentes da versão instalada: https://pypi.org/project/mutagen/#files .
- **FFmpeg / FFprobe** — não fazem parte do código-fonte e não são incluídos automaticamente. A licença depende da compilação: LGPL, GPL ou uma compilação não redistribuível com componentes `nonfree`. Use somente uma compilação redistribuível. O build aceita um diretório de binários e exige outro com as licenças, avisos e instruções/arquivos de fontes correspondentes da compilação utilizada. Não redistribua uma compilação sem atender às obrigações específicas. https://ffmpeg.org/legal.html .
- **Requests, urllib3, websockets, Brotli, PyCryptodome, certifi, charset-normalizer, idna** — licenças próprias incluídas em `packaging/licenses` e suas fontes nas páginas oficiais do PyPI das versões fixadas. Certifi usa a Mozilla Public License 2.0 para seu conjunto de certificados.
- **Python** — Python Software Foundation License; https://docs.python.org/3/license.html . O empacotador inclui os avisos da distribuição utilizada.
- **PyInstaller** — GPL com exceção para o bootloader; o aplicativo empacotado não precisa adotar a licença do empacotador por esse motivo. https://pyinstaller.org/en/stable/license.html .

Antes de publicar um pacote, mantenha os textos de licença, disponibilize o código-fonte correspondente exigido pelas dependências copyleft e identifique as versões exatas distribuídas. Não há binários de FFmpeg ou instaladores Windows no repositório.
